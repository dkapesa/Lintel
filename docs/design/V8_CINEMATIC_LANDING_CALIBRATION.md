## Responsive, material, motion and performance

Desktop lets the product stage carry more than half of the visual field. Compact desktop hides only the hero's decorative outline rail while retaining the real case state. Tablet and mobile use the existing logical document order and a bounded authentic crop; PR #482, recommendation, risk and pending decision remain present without miniaturising the desktop scene. Mobile does not receive sticky product ownership or horizontal overflow.

Dark remains near-black matte planes and light remains warm technical paper. Both use the same hierarchy and case geometry; no gradient, glow, glass or photo-like haze is added. V8B's observer and short opacity/transform emphasis are preserved. The calibration only changes static geometry and never adds looping, scroll-driven, parallax or layout animation. Existing reduced-motion selectors continue to force every record to its complete visible state.
