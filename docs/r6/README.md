# R6 — Authenticated Workstation Migration

R6 is the controlled migration of Lintel's authenticated application. It is
separate from, and must not reopen, the frozen R5 public product system.

## Authority

- [R6A — Programme Contract and Baseline](./R6A_PROGRAMME_CONTRACT_AND_BASELINE.md)
  is the accepted and frozen starting authority for subsequent R6 milestones.
  It records current owners,
  protected product truth, migration boundaries, fixtures, capability evidence
  and the R6 acceptance discipline.
- [R5 public-system freeze](../r5/R5E2H_FINAL_PUBLIC_SYSTEM_FREEZE.md) remains
  authoritative for every frozen public route and public design decision.

R6 later milestones may change authenticated presentation only within the R6A
contract. They must not create a parallel verification model, recommendation
source, Human Decision ledger, or public redesign.
